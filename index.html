Flagship Project

A toy compiler — and the RISC-V CPU I built to run it

A language with no built-in multiplication, compiled by a hand-written Rust toolchain into RISC-V assembly, executed on a single-cycle CPU I designed and wrote testbenches for — then debugged waveform by waveform in Surfer.

The full write-up covers the language and register-allocation decisions, the build process end to end, and a real bug that only showed up once the compiler, CPU, and testbench were running together.
